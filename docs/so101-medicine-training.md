# SO-101 药瓶入盒：真实示范与 π₀.₅ 微调

目标：这台 SO-101 从桌面抓起白色药瓶，放入棕色纸盒，松开夹爪并撤离。原始 `pi05_base` 作为微调起点。已有合成/真实观测推理记录不是示范数据，不纳入训练。

## 当前准备情况

已提供人操作主从臂采集窗口、两路相机预览、异步图像写入、成功/无效标记、逐条数据检查，以及面向云端现有 OpenPI 的 LeRobot v2 转换工具。尚未采集真实成功示范、计算真实训练统计或启动本任务微调。

设备配置：主臂 COM5，从臂 COM6；采集程序通过 DirectShow 按名称自动匹配主视角 Web Camera 和腕部 2M，并在窗口和每条数据的元信息中记录实际编号。重新插拔后编号可能变化；2026-11-15 最近一次检查为主视角 1、腕部 2，两路均已通过读取检查。校准分别读取 `my_leader_arm.json` 和 `my_follower_ik.json`；程序只验证保存值与电机寄存器，不修改校准。

## 第一条示范

先接好两台机械臂 USB 数据线与所需电源，运行只读检查：

```powershell
& E:\pi0.5\vendor\pi05-probe-client\Scripts\python.exe E:\pi0.5\scripts\collect_so101_medicine.py --check
```

启动采集窗口：

```powershell
& E:\pi0.5\scripts\start_so101_medicine_collection.ps1
```

1. 主视角固定，完整看到药瓶、纸盒和从臂抓放区域。先确定两路画面没有接反；采集后续示范时保持相机位置不变。
2. 托住主臂，点击“开始跟随”。相对跟随保留两臂启动时姿态差；先确认主臂各关节与夹爪能平稳控制从臂。
3. 将从臂通过主臂移动至统一的准备姿态，再按 **R** 开始记录。
4. 完整示范靠近药瓶、抓稳、抬起、移动到盒子内部、放下、松开夹爪和撤离；完成后停留约 1 秒。
5. 成功按 **S**；滑落、碰撞、没放进盒子等失败按 **D**。两者都会暂停跟随，从臂保持。只有 S 标记的示范才是训练候选；保存不自动证明任务成功或数据质量合格。
6. 使用主臂重新跟随并复位，不要强掰通电保持的从臂。需要手动摆放从臂时，先托稳，再点“已托稳从臂：解除电机保持”。复位和人工摆放物体的过程不要录入下一条任务。

空格暂停、Esc 退出；若正在录制，会将本条标记无效。断开 USB、相机帧过期、写盘跟不上或控制超时也会停止本条记录。暂停/退出后电机可能保持，断电前应托住从臂。

第一条录完先停下来检查，不要立即重复几十次：

```powershell
& E:\pi0.5\vendor\pi05-probe-client\Scripts\python.exe E:\pi0.5\scripts\so101_demo_data.py E:\pi0.5\data\so101-medicine\raw
```

检查会拒绝缺图、样本数不符、超过校准范围、采样间隔异常或相机与关节时间错位的数据。通过检查后还要人工查看任务完整性。

## 数据与动作约定

- 目标采样及控制频率 10 Hz。遥操作每次回调记录真实从臂状态，并保存本次经实际关节范围检查后下发的六维绝对目标，未用主臂原始值冒充从臂动作。按用户要求已移除额外的约 22°/秒软件限速和 64 ticks 跟踪偏差停机检查；保留实际校准范围、异常读数、通信及电机故障检查。
- 关节顺序：shoulder_pan、shoulder_lift、elbow_flex、wrist_flex、wrist_roll、gripper。
- 原始位置和动作均保存电机 encoder tick，同时保存完整校准和 SHA256。转换时按同一校准范围线性缩放到 [-1,1]，训练与推理必须使用相同转换，随后再由 OpenPI 做训练统计量归一化。
- 两路图像均按原始比例缩放并补边至 224×224，以 JPEG 保存。记录相机时间、状态读取时间、动作下发时间。
- 每条在 `data/so101-medicine/raw/episode-时间/` 下保存 `metadata.json`、`samples.jsonl` 和 `front/`、`wrist/` 图像。无效或未完成示范保留但不参与转换。
- 协议名 `so101-calibrated-range-absolute6-v1`。它与当前基础模型的只读 probe 协议不同，训练后的真机部署必须加载对应适配器、校准指纹和训练统计量。

## 批量采集与训练顺序

第一条通过图像、时间和动作检查后，先以约 30 条成功示范作为一轮起点；这不是足够学会任务的保证。覆盖实际计划使用范围内不同药瓶起始位置、夹爪接近姿态和少量盒子位置变化。保留完整的任务过程，避免只记录抓住药瓶后的部分。

在训练前按完整 episode 划分训练和留出集，不按帧随机混合。转换器默认固定种子选出 5 条留出示范，训练统计只允许从训练集计算；首次划分后保留 `split_manifest.json`，不要为了提高指标反复重划。额外保留未用于调参的真机测试摆放条件。

转换器运行在云端已有的 OpenPI Python 环境（该环境使用 LeRobot v2 API），不直接使用本地 vendored LeRobot v3 API：

```bash
python convert_so101_medicine.py /path/to/raw /path/to/new-output --held-out 5
```

只有一条试录时可以使用 `--pilot-only` 验证转换格式，但产物不能冒充正式训练/评估划分。

后续依次完成：真实数据转换与读回 → 从训练集计算归一化统计 → 为六维 SO-101 绝对动作配置输入/输出适配 → 从官方 pi05_base 做 4090 LoRA 显存和训练小步检查 → 完整训练 → 留出动作诊断及受控真机闭环评估。训练损失下降不能替代药瓶入盒成功率。
